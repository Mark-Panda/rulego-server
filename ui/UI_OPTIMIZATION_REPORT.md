## 🔧 技术实现细节

### 样式架构
```scss
// 渐变背景系统
background: linear-gradient(135deg, start-color, end-color)

// 多层阴影体系  
box-shadow: 
  0 8px 32px rgba(0, 0, 0, 0.12),    // 外阴影
  0 4px 16px rgba(0, 0, 0, 0.08),    // 中阴影  
  inset 0 1px 0 rgba(255, 255, 255, 0.3) // 内高光

// 高级过渡动画
transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1)
```

### 响应式断点
- **桌面端**: > 1200px (420px侧边栏)
- **平板端**: 768px - 1200px (380px侧边栏)  
- **移动端**: < 768px (全屏 + 遮罩)

### 动画系统
- **侧边栏滑动**: `sidebar-slide` transition
- **遮罩渐变**: `overlay-fade` transition
- **按钮悬停**: 3D变换 + 缩放效果
- **工具栏适配**: 智能位置调整
